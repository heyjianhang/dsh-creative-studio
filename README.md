# 创作 · DSH Creative Studio

DSH 原生创作画布插件，包名 `dsh-creative-studio`。当前版本 `0.2.26`，包含模板参考图导入及生成错误提示修复；未发布到 npm。

## 已实现

- 点击 DSH 侧栏「创作」，在正常内容区进入我的项目与模板库；打开项目后进入全屏画布。
- 模板库分图片 / 视频 / 画布；图片接入 Image Prompt Registry 的真实效果图和提示词，支持用途分类、搜索、来源、原模型、收藏与详情。使用时创建画布或在当前画布新增节点，带入提示词与所选参考图，不自动生成。
- 项目搜索、最近编辑/名称排序、卡片/列表视图；项目新建、改名、删除、自动保存与重新打开。
- 选中节点上方提供彩色 Pin 标记、存入创作素材、下载和放大；上下操作面板始终锚定素材，不自动避让屏幕边缘、不自动平移视口；同一画布分别记住文本/图片/视频的模型、参数和数量，新节点继承。
- 悬浮工具栏；点击加号或双击画布空白，创建文本、图片、视频节点；同一菜单的「添加资源」分组提供「上传」和「素材库」。
- 画布左上项目切换器：搜索、缩略图、当前项目标记、直接切换与新建；切换前保存当前修改。重命名在项目列表操作。
- 上传、拖入、粘贴媒体；普通点击单选、Shift 点击多选；节点拖动、连线、框选、复制、删除、撤销/重做；保存视口。
- 底部小地图可展开/收起并拖动定位；适应画布、缩放滑块和百分比重置。空白拖动平移，Shift 拖动框选；触控板双指平移、捏合缩放，Ctrl/⌘ + 滚轮缩放。
- 画布和素材选择共用沉浸式预览：媒体保持原比例，右侧显示真实分辨率、格式、大小与视频时长；可下载原文件、复制描述，以及按来源加入画布或存入创作素材。视频自动播放，Esc 返回后保留浏览状态。
- 视频画面支持单击播放/暂停、拖动节点与触控板缩放，左上角提供声音开关，当前画布记住静音状态；悬停时显示播放、时间、进度和放大控制。双击只进入预览并暂停画布原视频；需要全屏时点击预览播放器的全屏按钮。
- 统一「素材库」面板，顶部切换「创作素材 / 素材库」。创作素材采用可展开的文件夹列表，标题旁可选择「个人 / 当前项目」。默认角色、场景、道具、风格、音效、其他文件夹；可新建子文件夹、改名、删除（内容移到上级）。个人素材跨项目复用，项目素材独立保存。
- 两个页签统一使用缩略图列表，悬停出现等比例图片或静音循环视频，移入预览卡片仍可继续浏览；点击条目或「应用到画布」直接添加。创作素材右侧「…」可重命名、移动、创建副本、下载与移除；副本复用原文件，移除不影响已加入画布的内容。
- 本地上传、从画布存入素材、名称/描述自动保存、参考增删、移除记录；保留原文件与画布引用。存入创作素材仅打开文件夹选择。上传及添加素材不改变当前视口和缩放。
- 下载先准备原文件，再确认文件名并保存；支持浏览器原生保存选择器时可选择位置。无该能力的浏览器使用其下载设置决定位置；只在原生写入完成后提示已保存，浏览器接管时明确提示已交给浏览器。
- 创作素材加号提供「上传 / 从素材库添加 / 新建文件夹」，上传后选择目标文件夹，批量保存。素材库页签直接浏览独立插件资源，点击直接加入画布，Shift 点击或勾选可批量「添加到画布」或「存入创作素材」。AI 默认开启，复用原索引，支持请求取消、失败回退、类型和库筛选、方向键导航与空格预览。
- 文本节点的正文与生成指令独立编辑；底部悬浮面板选择 DSH 已配置模型和 1–4 个结果，支持流式查看、停止、重试及正文历史恢复。
- 文本、图片与视频使用统一模型菜单，厂商紧随模型名称；文本模型按实际元数据展示图片输入、上下文与默认输出。卡片连接点在悬停、键盘聚焦或连线时出现。
- 从画布选择文字/图片参考，或在指令中通过 `@` 插入引用芯片。未被 `@` 点名的参考仍会发送；不支持的节点置灰。第一份结果写回原节点，其余方案另建节点；生成期间修改正文时保留修改，结果另建节点。
- 项目独立的 DSH 原生 Agent 对话面板，复用模型、附件、授权和会话机制。
- 跟随 DSH 主题；原生导航、设置入口及中英文文案。

- DSH 原生设置「创作」支持多个火山方舟 / 火山Agent Plan 连接。填写 Key 后获取官方在线模型目录，搜索、按图片/视频筛选、勾选批量添加；可以刷新目录、设置默认模型与默认参数，密钥不会读回客户端。
- 模型 ID 与参数支持范围读取火山官方文档，参数自动匹配，不再要求手选能力预设。未识别协议的模型显示待适配；旧配置保持兼容。获取失败使用标明时间的缓存或随包目录；目录发现不代表账号已开通对应权限。
- 图片与视频节点支持提示词、画布文字/图片参考和 `@`；图片可设置比例、清晰度、1–4 个结果；视频可设置首尾帧或多图参考、比例、清晰度、时长、音频，由所选模型的能力快照约束。首尾帧采用独立槽位，可交换图片；带图片时使用自适应比例。模型选择器直接列出模型，厂商放在模型名后，保留分辨率、时长和音频能力；参数面板按模型能力生成分组控件，时长可横向滚动且不显示滚动条。
- 文字流式内容与文字生成状态显示在卡片；图片/视频生成卡片显示动效，下方发送按钮显示忙碌动画，失败与重试显示在输入面板。上传、素材库引用与生成结果选中后均可输入新提示词继续生成；上传原件保留，新输出另建节点。输入框可以继续编辑。生成结果保存到本地媒体目录，双击预览、下载或存入创作素材。
- 视频任务远程 ID 持久化，重启后恢复查询；下载失败只重取已有结果。提交结果无法确认时明确标记，不自动重新提交付费请求。生成卡片与预览展示模型、计费方式和接口返回的用量；接口用量不等于实付金额。

**主体一致性专用流程、时间线、视频与画布模板渠道尚未实现。** 图片模板已接入在线渠道并缓存在本机。文本生成已有持久化队列（最多两个并发）；节点连线不会自动触发生成。

## 安装

目标版本：DSH `0.2.1-rc.3`、Cordis `4.0.5`，Node.js >=22.19。

在 DSH「插件 → 添加插件」中输入以下任一来源：

- GitHub：`https://github.com/heyjianhang/dsh-creative-studio.git`。仓库现已公开，可直接使用；推荐固定版本：`https://github.com/heyjianhang/dsh-creative-studio.git#v0.2.26`。
- 本机安装包：构建好的 `dsh-creative-studio-0.2.26.tgz` 的绝对路径。
- 本机源码目录：先执行 `npm ci && npm run check`，再填写仓库绝对路径。

仓库已提交构建好的 `lib/`，Git 安装直接使用 Host/Client 产物，不执行本插件的构建脚本，也不需要为插件添加 `allowBuilds`。包尚未发布到 npm，不能直接填裸包名 `dsh-creative-studio`。

CLI 安装本地包：

```sh
dsh plugin --profile YOUR_PROFILE add /absolute/path/dsh-creative-studio-0.2.26.tgz
```

图形安装器安装后默认启用 bundle，侧栏出现「创作」。CLI `add` 安装依赖后还需在插件页启用；自行管理 profile 时将 `dsh-creative-studio` 加入 `dsh.profile.bundles`。本机 tarball 已在隔离 profile 安装加载；远程 Git 安装验证见[验证记录](docs/studio.md)。Windows 安装尚未实机验证。

素材库是可选依赖，已验证与 `dsh-asset-library@0.6.8` 同时安装加载。未启用时仍可使用本地上传。文本优化和助手使用 DSH 已配置的模型与密钥；文字密钥由 DSH 管理；图片/视频连接的密钥由本插件 Host 存储。隔离预览未配置密钥时会显示可理解的错误，不影响画布操作。

## 使用

1. 从 DSH 侧栏打开「创作」，进入我的项目；新建或打开项目进入全屏画布。
2. 点击悬浮加号或双击空白添加节点；文件也可直接拖入。
3. 在 DSH 设置 → 创作 → 选择供应商，在同一表单顶部选择「火山方舟」或「火山Agent Plan」，下方切换对应 Key 提示和默认 API 地址。连接弹窗点「保存 / 保存并添加模型」即写入本机；重开时密钥不回显，留空保留已保存密钥。Base URL 已预填且直接显示，可按需修改；进入对应模型列表后勾选添加即保存。接入点可通过「手动添加模型 / 接入点」填写 ID，并选择它实际绑定的模型作为参数来源。模型列表来自官方公开目录；填入 Key 不代表已获得调用权限。选择图片/视频节点后即可选择已添加模型与参数。生成结果持久保留，可双击预览并存入创作素材。
   已有连接也能切换供应商：已保存的 Key 保留，原供应商的模型需重新选择。方舟按量 Key 与 Agent Plan 专属 Key 不通用；两种模式分别使用 `/api/v3` 与 `/api/plan/v3`。旧模型可在「模型设置 → 重新选择模型」中替换并保留节点的模型标识。配置错误在卡片提供「检查设置」入口；目录/地址不匹配在付费提交前拦截，404 也可能代表账号无访问权限。新提交的重试采用已修改的模型配置，已有远程结果只恢复查询或下载。
4. 选择文本节点，在下方浮层填写生成要求，选择模型和数量；加号从画布选参考，`@` 明确指向素材。⌘/Ctrl+Enter 开始生成。双击文本节点或点击编辑按钮可直接修改正文。节点两侧圆点用于连线，连入文本节点会添加参考。
5. 打开「添加资源 → 素材库」。在「创作素材」展开文件夹，标题旁选择个人/当前项目；加号可上传并选存放文件夹。切到「素材库」可直接浏览、AI 搜索原库资源，多选后加入画布，或选择文件夹存入创作素材。页签各自保留查询与筛选，关闭面板后重置。
6. 选中画布图片/视频，用「存入创作素材」选择目标文件夹。文件夹内悬停预览，点击加入画布；条目右侧「…」管理名称、副本与所在文件夹。Agent 可调用 `creative_assets_search` 查找创作素材。
7. 打开「模板库」按图片用途浏览，悬停星标收藏，点击卡片查看效果与提示词，再点「使用提示词」。模板提供的独立参考图默认带入；没有独立参考图时，默认带入效果图作为风格参考，可取消。所选图片保存到本地项目，并自动连入生成节点。项目页创建新画布；画布入口在当前项目插入节点，不改变缩放。原模型仅作出处说明，不自动生成。目录同步失败时已有缓存仍可使用；外部图片可访问性取决于原站。详见 [模板库](docs/templates.md)。
8. 画布左上返回项目列表，恢复 DSH 主侧栏。修改自动保存，重新打开恢复节点、连线和视口。

快捷键：⌘/Ctrl+D 复制，⌘/Ctrl+C/V 复制粘贴，⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做，Delete/Backspace 删除，Esc 关闭当前浮层，按住空格拖动画布。双击图片或视频打开预览；预览画面获得焦点时，空格播放/暂停视频。素材面板中方向键切换、空格预览、Esc 返回，预览关闭后保留搜索条件。输入框保留文本编辑快捷键。

## 数据与限制

项目数据由 DSH `storageDomain` 的 `creative_studio` 域保存；创作素材单独存于 `creative_library` v1，文件夹存于 `creative_folders` v1，不改变原项目域版本。旧创作素材仍按原分类对应默认文件夹，重命名不会改变归属。媒体默认在 `$DSH_HOME/creative-studio/media`，项目助手工作目录在同一根目录的 `projects/<id>` 下。可通过 Host 配置 `dataDir` 修改媒体根目录。

项目保存有版本检查，并发修改不会静默覆盖；写入失败保留当前编辑和浏览器草稿，可重试。卸载插件保留本地数据。删除项目移除项目记录，媒体文件暂时保留；当前未提供自动垃圾清理或完整迁移包。

每次最多批量添加 100 个素材，每项创作素材最多 24 个参考。文件夹最多 6 层。当前只接入图片和视频文件；「音效」只是预设文件夹，音频导入与音频节点尚未接入。范围中的「当前项目」为项目独立空间，尚无多人团队空间。搜索合并名称、描述、分类和参考文件名匹配，以及原素材库参考的语义匹配。仅上传到创作插件的本地文件目前没有向量索引，只能文字匹配；需要语义检索的文件可先导入原素材库并完成索引，再在这里选取。界面会提示索引覆盖限制，不重复创建密钥设置或向量数据库。

单文件上限 256 MiB，按块上传。画布保留已浏览媒体，缩略图与预览复用会话缓存；后台读取按文件和分块限制并发，上传完成直接复用浏览器原文件。闲置缓存上限 256 MiB / 96 项、10 分钟回收；使用中的媒体不提前撤销。刷新浏览器后重新读取，视频首次仍需完整下载到 Blob 后播放。列表可见时才读取缩略媒体，本地视频从同一缓存读取画面，悬停预览复用原件。大量大型视频的代理预览、项目导出和跨设备迁移属于后续优化。素材库引用要求原库可用；关闭或移除库后，需要重新打开库才能访问。

## 开发

```sh
npm ci
npm run typecheck
npm run check:compatibility
npm test
npm run pack:release
```

- `src/shared`：Zod 数据与 Typert 契约。
- `src/host`：项目持久化、媒体上传、模型任务和工具。
- `src/client`：原生插件注册、项目页面、React Flow 画布和媒体。
- `tests`：保存并发、图校验、上传边界。

图片/视频生成已通过模拟供应商测试，覆盖多模型/密钥隔离、批量幂等、图片参考、视频远程 ID 恢复、取消、提交不确定、下载重试及结果保护。真实收费供应商调用尚未执行，参数与账户权限以实际接口为准，详见[图片与视频生成](docs/media-generation.md)。

文本生成已通过定向测试，覆盖模型与真实图片附件的适配、引用规则、结果保护、队列并发、取消、超时、重启恢复与重复提交。真实供应商调用尚未执行；详细验证状态见[文本生成](docs/text-generation.md)。此前素材和画布交互的验证边界见设计与验证记录。

[设计与验证记录](docs/studio.md)；[开发规则](AGENTS.md)。

开发工具箱来自 `heyjianhang/dsh-plugin-devkit`（Git remote `template`），业务实现独立维护。未复制参考生图插件或商业产品源码。

画布会按文本、图片、视频分别保存最近选择的模型、参数与数量，新节点沿用；已有节点保留自身配置。@ 只列出连入当前节点的兼容素材，添加参考请用 + 或拖动连线。圆形连接点支持扩大范围吸附，也可拖到目标卡片松手连接。生成期间发送按钮显示忙碌动效并可停止，媒体卡片显示扫光；错误仍在下方提供重试。

当前版本面向 DSH 0.2.1-rc.3；旧版 DSH 0.2.0-rc.2 请使用原有安装标签。安装无需版本豁免。
