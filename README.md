# 创作工作台

面向使用 ACTVERO Harness 进行视觉创作的用户，以及维护此包的开发人员。包名 `dsh-creative-studio`，本地预览版本以 `package.json` 为准，尚未发布。

## 安装与进入

在「工作台 → 我的工作台 → 导入工作台」选择本地 `.tgz`，加载后在侧栏工作台右侧选择「创作」。需要 ACTVERO 扩展 API 1.7 与 DSH 0.2.1-rc.3。本包内置素材库模块，请停用旧的独立素材库 bundle；业务目录、库 ID、项目、媒体和凭据保留。完整升级与数据规则见[使用与升级](docs/creative-workbench.md)。

工作台卡片附带适配圆形裁切的专属图标与三张咖啡主题演示截图。点击卡片预览可放大查看节点画布、素材库和模板详情。

## 可以做什么

- 三个管理页采用统一的顶栏与全宽布局；桌面搜索框固定宽度，窄窗口独占一行。素材主区域使用原比例、限制尺寸的瀑布流。收藏夹选择与管理、排序、标签和日期集中在右侧筛选抽屉，条件即时生效；重置和完成固定在底部，不挤压顶部工具栏。删除收藏夹保留素材。素材详情按需打开弹窗，大图预览占用窗口可用区域，图片默认完整显示；详情与大图均支持触控板双指平移、捏合缩放及双击切换原始大小。
- 我的项目：创建、重命名、搜索、排序、卡片或列表浏览、删除项目；打开后恢复节点、连线与视口，自动保存并检查并发版本，失败保留草稿。
- 画布：文字、图片、视频节点，连接参考、彩色 Pin、上传、复制、缩放、平移、Shift 多选、小地图、撤销重做、媒体预览和下载。文本与媒体生成面板保持节点锚定位置，底部工具栏在重叠时遮挡面板；上传原件与新生成结果分别保存。
- 素材库：本地与 S3、图片视频导入、标签、描述、单层收藏夹、分类检索、索引配置、批量任务及 ZIP 迁移。素材可归入多个收藏夹，删除收藏夹保留媒体。画布浮层复用共享收藏夹，浏览与搜索均显示媒体，清空搜索保留收藏夹范围；点击勾选，使用底部「添加到画布」批量插入。原有项目素材与参考组合数据保留。
- 模板库：在线图片提示词、用途、来源和原模型筛选，详情与参考图选择。项目顶栏更多菜单可将当前画布保存为本地模板，在「模板库 → 画布」新建项目，或从画布的模板库插入。应用模板不自动提交生成。视频模板仍待接入。
- AI 协作：宿主原生浮窗、模型、草稿与历史；右下角原生 AI 入口按当前项目打开或复用关联对话，等待画布保存后再绑定。随包创作助手可查找并检查素材，创建项目，放入文字/图片/视频节点，编辑提示词、位置、参考与连线，按已配置模型提交生成并查询、取消或重试任务。Host 在画布关闭时仍保存完成结果；项目级对话固定操作关联项目，管理页对话可创建项目。普通新会话不继承工作台工具。
- 生成设置：保留火山方舟、火山 Agent Plan、多连接、多模型、目录发现、模型参数、生成数量及默认偏好。密钥由 Host 保存，不回传客户端。文字使用 DSH 模型，图片视频沿用供应商授权；模型目录不代表账户已有调用权限。

## 开发与校验

三个管理页在全局页签下直接显示工具栏与内容，不重复页面标题。搜索、类型切换、下拉选择、筛选抽屉、卡片和媒体瀑布流共用 collection-ui.tsx 与 collection.module.css；画布素材面板也复用相同控件。布局根据工作台容器宽度调整，支持深浅主题、键盘焦点和减少动态效果；尺寸、状态与验收要求见 [DESIGN.md](DESIGN.md)。新增页面先复用这些组件，避免单独定义另一套控件尺度。

先准备已构建的 ACTVERO 源码工具链；首次安装依赖用 `npm ci`，再运行 `npm run bind:workbench -- /绝对路径/actvero-harness` 绑定能力包类型。业务包不内置宿主能力模块，运行时由 ACTVERO 提供。项目使用 Host/Client 两份类型配置，分别执行检查。

在本项目目录运行：

```sh
npm run typecheck
npm test
npm run build
npm run check:package
npm run check:compatibility
npm pack --pack-destination ..
```

本地开发使用同版本的 ACTVERO 能力包类型产物。Host/Client 从 package.json 和 workbench.json 读取相同身份及协议；Client 外部复用宿主 React、Store 和 Primitives。发布文件包含已构建 lib/，不使用安装生命周期构建钩子。图标通过宿主元数据读取器校验，文件不得超过 256 KiB；每张工作台预览图不得超过 128 KiB，`check:package` 会拒绝不符合限制的资源。详情见 [DESIGN.md](DESIGN.md)、[画布](docs/studio.md)、[文本生成](docs/text-generation.md)、[媒体生成](docs/media-generation.md) 、[创作助手流程](docs/agent-workflow.md)与[模板](docs/templates.md)。旧文档中的独立侧栏与助手展示方式以本文件为准。

## 数据与验证范围

业务数据仍由原有 Host 服务负责：项目存于 creative_studio，参考组合与文件夹存于 creative_library / creative_folders，文本与媒体任务保留原有存储域；媒体默认为 `$DSH_HOME/creative-studio/media`，共享库沿用 asset-library 目录，可使用原有本地/S3 存储。宿主仅保存工作台实例及对话关联，不复制业务数据。卸载保留数据；删除项目目前保留媒体文件，不提供自动垃圾清理。

本地业务、存储升级、队列、取消、错误恢复和模拟供应商由自动测试覆盖；在独立 DSH_HOME 验证安装、原生入口、管理页面、旧画布与 AI 绑定。真实模型生成、付费向量索引、S3 联网和 Windows 安装需分别验证，不能用本机预览代替。
