# 创作合并版使用与升级

本文面向试用合并版的用户与安装维护人员，说明入口、收藏夹和数据兼容性。

通过「工作台 → 我的工作台 → 导入工作台」安装本地 .tgz，加载后从侧栏工作台右侧选择「创作」。顶部可切换我的项目、素材库和模板库。三页使用全宽内容区，素材库内容区以直角衔接页面边缘。收藏夹导航位于位置栏浮层，所有收藏夹平铺显示；主区域仅展示当前收藏夹素材或全部素材；缩略图在 192×192 px 内按原比例完整显示，窄窗口排列两列，图片下不显示名称、大小或索引状态。点击图片打开详情：桌面左侧预览、右侧展示信息并编辑收藏夹、标签和备注；窄窗口上下排列。详情自动保存，关闭后返回原浏览位置。图片预览支持缩放、原始大小、适应窗口、拖动查看和下载；详情与大图预览共用图片操作，触控板双指滑动平移、捏合围绕指针缩放，双击切换原始大小与适应窗口，Ctrl/Command 加滚轮也可缩放。大图预览填满弹窗可用高度，关闭后返回原详情；视频支持播放暂停、进度、音量和全屏。画布素材面板使用顶部下拉切换收藏夹，并可按图片或视频筛选。面板内以两列缩略图展示素材，搜索限于当前范围；清空搜索返回原浏览位置。选中的缩略图按顺序编号，可通过底部「添加到画布」统一插入。收藏夹菜单支持新建、改名及删除。位置按钮显示「全部素材」或当前收藏夹名称；悬停或聚焦行尾时，数量切换为「…」，点击可重命名或删除，触屏始终显示操作按钮。键盘右方向键可打开操作菜单，Escape 或左方向键返回收藏夹列表。默认收藏夹不提供重命名和删除。收藏夹只保留一层，同库名称不能重复，一个素材可加入多个收藏夹。画布素材面板直接显示统一素材库，不再显示「全部素材／当前项目／我的参考组合」来源切换；旧创作资料保留。选中画布中的图片或视频后，节点工具条提供「存入素材库」或「加入收藏夹」。新文件可以直接存入素材库或选定收藏夹，按内容去重复用已有文件。素材库引用可直接追加收藏夹归属。操作完成后提示保存位置。

本包内置素材库模块，不能同时启用旧 dsh-asset-library bundle，否则会重复注册数据服务。停用旧 bundle 不删除旧文件，合并版继续使用原来的 asset-library 目录及凭据命名。首次没有已登记的库时创建空的本地个人素材库；已有库加载失败时保留失败状态，不新建替代库。

首次打开将库内 SQLite 升为版本 5。旧子文件夹提升为独立收藏夹，重名时加编号，保留分类和素材 ID、归属、标签与原文件。删除收藏夹只移除这一项归属，素材继续留在库中。升级前备份与恢复步骤见[收藏夹升级说明](upgrade-collections.md)。

ZIP 保持版本 2，新导出的收藏夹没有层级；导入旧 ZIP 时将层级平铺，重名时自动编号。

原生工作台以同一个包名升级，要求 ACTVERO 扩展 API 1.7 与 DSH 0.2.1-rc.3；旧版仅有普通插件入口的宿主不支持此版本。业务界面、顶栏、工作台设置和原生 AI 均由工作台注册。管理界面和画布共用项目状态，缩放、节点与生成操作保留。

点击右下角原生 AI 入口，先保存画布，再创建或恢复绑定当前项目的原生对话；管理页打开实例级对话。画布顶栏只保留业务返回、项目名称和保存状态，公共返回列表入口通过 catalogButton 选项隐藏。绑定后在另一个窗口切换项目不会改变当前对话工具目标。创作工具、素材工具与随包创作及素材 Skill 仅在工作台关联对话中提供，普通新会话不自动获得。原有独立项目助手会话与内容保留，新讨论不改写旧会话。生成配置与多参考组合保留；生成结果自动归档至共享素材库尚未完成。真实 AI 生成需要配置模型和凭据，预览不自动发送付费请求。

模板库保留类型、用途、来源、模型、详情与应用流程，不再显示模板收藏入口；历史收藏数据仍保留。素材库把搜索与媒体类型放在一起，把数量、排序与筛选放在结果侧。窄窗口下工具栏自动换行。任务、库管理和 ZIP 导入导出位于右上角更多菜单，素材详情按需打开弹窗，筛选从右侧抽屉打开并即时生效。抽屉底部固定提供重置和完成；顶部仅保留固定宽度的筛选按钮与条件数量。向当前收藏夹导入素材会追加收藏夹关系；重复素材保留原有关系。editAsset 的 addCollections 为原子追加，不替换已有分类，收藏夹失效时不提交此次编辑。

顶部三页导航相对整个业务顶栏居中。素材收藏夹的悬停与选中背景仅作用于整行，内部按钮保留键盘焦点。画布图片、视频节点根据媒体原始比例收紧，完整显示内容；初始内容尺寸不超过 270×340px，小图保持原尺寸，画布仍可整体缩放和平移。该显示尺寸不改写项目数据。提示词面板保持节点锚定位置，不自动避让或缩高；底部工具栏显示在面板上层，重叠时正常遮挡，超出画布的内容由画布裁切。不为面板移动或缩放画布。

画布顶栏显示返回、项目名称和保存状态，不显示分隔竖线或项目下拉；切换项目先返回列表。快捷键入口位于左侧画布工具栏，打开可用 Escape 关闭的说明弹窗；右下角保留框架的 AI 入口。

画布连线贴近节点边缘，连接点只在悬停、键盘聚焦或连线时显示；可见圆点外仍保留 36px 指针热区及原有拖入卡片的连接容错。

从我的项目、素材库或模板库右上角的齿轮进入同一页「创作设置」，也可从 DSH 设置的「创作」进入。「模型连接」配置供应商与图片、视频和向量模型，「素材库」配置 AI 索引、存储、任务处理与 ZIP 迁移。

在「模型连接」打开火山方舟官方按量连接的「添加模型 → 向量」，添加并启用多模态向量模型。随后在「素材库 → AI 索引」选择向量模型，通过「测试模型」核对权限。素材库保存模型 ID，由宿主从所属连接读取地址和密钥。所选模型或连接停用、移除后，素材库显示不可用并可重新选择。更换 API 地址、向量模型或视频分段长度后需重建索引。

升级后，已有的独立连接和手填接入点只读沿用，直到用户选用「模型连接」中已配置的向量模型。没有可选模型时，AI 索引显示当前状态和「前往模型连接」按钮。需要继续使用原来的接入点时，可在「模型连接」用「手动添加模型 / 接入点」添加，再到素材库选择。

首次进入创作默认采用专注布局，收起 DSH 侧栏，不切换操作系统全屏；用户手动修改侧栏后沿用框架记忆，离开工作台恢复原来的导航状态。

项目卡片的更多按钮与项目标题垂直居中，标题预留按钮宽度以避免长名称重叠；列表视图仍将按钮放在整行右侧。

创作助手可通过同一套 Host 服务创建项目、编辑节点与参考、查询模型、提交生成并同步结果。项目级会话只允许操作绑定项目；从管理页打开的会话可创建和管理其他项目。生成完成后 Host 自动合并结果到最新项目，版本冲突保留用户草稿，重复请求复用任务，结果写入失败可再次查询恢复。完整工具与验收见[创作助手流程](agent-workflow.md)。

画布素材浮层采用紧凑尺寸：桌面宽度不超过 300px、高度不超过 480px，收藏夹图标为 18px、行高至少 36px，标题操作图标为 16px 并保留 32px 点击区域；触屏标题操作保留 44px 点击区域。窗口较小时面板按可用空间收缩，长列表在面板内部滚动。

素材管理与画布选取的收藏夹导航、多选及媒体比例规则见 [设计说明](../DESIGN.md)。
