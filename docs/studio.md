文本节点已升级为独立指令输入、画布参考、@ 引用、原生模型切换和持久化生成队列，最新设计及验证见 [文本生成与参考](text-generation.md)。下方「文本优化」描述保留早期阶段背景，当前以该文档为准。

## 目标与验收

用户确认：原生 DSH 插件「创作」，从 DSH 主侧栏进入正常内容区的「我的项目」，顶部切换模板库；仅打开具体项目后进入全屏画布，左上返回项目列表。不设首页和二级插件侧栏；所有生成在画布内。画布采用悬浮工具，只有一个添加入口，双击空白弹出相同菜单；主题跟随宿主。第一阶段交付可安装包、项目管理与自动保存、文本/图片/视频节点、上传、素材库读取、DSH 文本优化和原生 Agent 面板接入。图片/视频生成队列、主体与模板内容系统属于后续阶段。

验收：安装后有原生入口；创建项目、添加/连线/复制/删除/撤销；导入真实文件、从素材库加入；离开重开恢复布局；文本优化支持输出、取消及错误；Agent 绑定独立项目会话；卸载插件释放服务和界面，数据保留。

添加入口统一在悬浮加号与双击空白菜单：上方「添加节点」提供文本、图片、视频，下方「添加资源」仅含「上传」和「素材库」。工具栏移除重复的素材库入口。后者调用已有 dsh-asset-library 的 assetLibrary 服务搜索和读取，保存素材 ID 引用；未启用插件时保留错误提示。本地上传及库中选取均沿用打开菜单时的画布坐标，避免关闭菜单后位置丢失；取消文件选择清除待替换目标。菜单使用原生 portal 自动避让窗口边缘。本轮只做类型检查与构建，未恢复浏览器验证。

## 基线与依据

DSH 0.2.0-rc.2、Cordis 4.0.5、React 18、Node >=22.19。源自 heyjianhang/dsh-plugin-devkit；按已安装类型和本机相同版本 DSH 源码核对。React Flow 使用自定义 React 节点和 SVG 连线；只加载 base.css，界面消费宿主语义 token。UI 通过 sidebar.panellist 注册入口，main 承载项目/模板列表页，shell.overlay 仅在项目打开时承载全屏画布；不替换宿主 root，不修改原有侧栏折叠状态。settings.section 与自定义 Session slot 保留。全屏容器复用 useModalLayer 管理焦点和弹层按键，画布快捷键跳过自身容器但保留对子弹窗的避让。Agent 采用 SessionProvider + conversation.content（embedded），不使用私有 DOM 挂载。

## 数据与边界

Host 是业务所有者。项目放在 DSH storageDomain；媒体是插件自有目录内受控 UUID 文件；素材库引用保存 libraryId/assetId，经服务读取，不操作其数据库。项目快照带 revision，串行写入 + 乐观锁阻止覆盖；UI 保存队列合并变更并保留失败草稿。文本优化走 ctx.llm 与 agentDefaultModel，凭据由宿主管理。

src/shared：Zod 数据与 Typert 契约；src/host：项目、上传、媒体、模型调用；src/client：宿主注册、项目导航、画布、媒体与自动保存。测试覆盖版本冲突、图校验、存储失败和上传边界；真实隔离 profile 检查安装与交互。不修改用户宿主源码或个人 profile。

### 创作素材库整合（首版，界面由下方文件夹方案替代）

用户确认同一个「素材库」入口分「创作素材 / 全部素材」。前者为可跨项目复用的角色、场景、道具、风格与其他素材，包含名称、描述和多份图片/视频参考；后者浏览已有资源管理插件。上传可整理成创作素材，画布节点可存为素材，已有库素材只记录引用。删除创作记录不删原文件和已加入画布的内容。

实现路径：新增独立 creative_library v1 存储域（不更改旧项目域版本），Host 的 creative-assets.ts 管理记录、版本冲突与组合搜索；library-search.ts 通过 assetLibrary.snapshot/search/media 公共服务适配库筛选、语义检索和失败降级。客户端独立素材面板负责双页签、分类、搜索、组合参考图、详情编辑、上传与画布插入。现有契约扩展可选 creativeAssetId 以识别项目使用情况。验收包括跨项目引用和删除独立性、过滤/分页、AI 请求取消和普通搜索回退。

AI 默认开启，输入防抖并取消过时请求；搜索按相关度排列，未输入时浏览最近素材。创作素材的名称/描述检索与其原库参考图的语义分数合并；本地新上传尚无多模态索引时只做文字匹配，界面说明覆盖范围，不伪装为已索引。复用原素材库凭据与模型，避免新增密钥配置。当前支持图片和视频，不展示尚不能使用的音效/3D 入口。本轮沿用用户暂停浏览器验证的要求，执行类型检查、构建和隔离预览更新，未完成的实测明确保留。

模板库仅预留导航与明确空态；尚无在线模板渠道。首版单次媒体上限 256 MiB，按块传输。Agent 工具和界面共用项目服务；真实图/视频生成将在第二阶段接入。

整合交互：面板内部滚动、窄窗口适配；两列等比例卡片、按需加载、空态和搜索骨架；方向键接续鼠标活动项，空格预览，Esc 分层返回；预览返回保留查询，关闭面板后重新打开重置。原生 Menu 选择库/类型/分类，顶部提供筛选重置。多选直接加入画布或整理为一项创作素材，最多 24 份参考，按来源 ID 去重。批量添加共用一次撤销记录，节点保留素材名称、描述与 creativeAssetId。

新增确认、已有素材自动保存；写入串行带 revision，失败保留输入并提供重试/重新载入。补充原库参考时保留草稿，返回后按正确 revision 自动保存。删除只移除创作记录。媒体读取检查项目所有权、创作素材引用或当前项目已有节点引用；本地视频列表使用图标，主动预览时才读取原文件。

新增契约：libraryInfo/searchLibrary/creativeAssets/getCreativeAsset/createCreativeAsset/updateCreativeAsset/removeCreativeAsset。客户端 asset-library.tsx 负责搜索与面板，asset-editor.tsx 负责组合与保存，asset-shared.tsx 负责缩略卡/选择器。Agent 的 creative_assets_search 复用同一搜索命令与校验。AI 查询设置 30 秒请求超时，失败回退文字匹配；部分索引覆盖为保守提示，原素材库未提供逐引用的索引状态。当前提供创作分类和多参考组织，尚未实现主体一致性生成。

目标与验收：平移离开素材再返回不重建已加载的媒体、不重复读取；同一素材的画布/缩略图/预览复用读取；视频首次读取不再逐块串行；自动保存与空闲任务轮询不丢失节点测量、小地图不因平移改变场景比例。数量菜单向上且与按钮等宽。验证覆盖缓存并发/取消/淘汰/异常重试、节点状态合并及真实宿主平移/预览/小地图。

设计：Client 内由请求会话拥有共享媒体缓存，进行中的读取合并、有限并发、闲置 LRU/超时回收，活动引用不提前撤销；上传完成直接缓存浏览器原 File。画布保留节点 DOM，媒体初次接近视野才读取，离开时暂停视频；自动保存使用不可变快照引用，图更新保留节点运行期测量；无变化的轮询不重复更新。新增缓存、读取和节点合并模块以便独立测试；Host 请求契约不变。首次视频仍需取得完整 Blob 才播放，当前宿主没有为本插件暴露已核验的 HTTP Range 媒体地址，不伪称流式播放。跨浏览器刷新缓存不落盘，原件继续由 Host/素材库持有。

验证结果：Host/Client 类型检查、59 项测试及双端构建通过，已安装到隔离 creative-test，预览为 4321。用自有图片与 12 秒视频完成离开视野再返回、视频放大预览，以及自动保存后的三轮往返平移：媒体 Blob URL 未变化、节点保留，小地图场景范围和同一缩放下视野框尺寸未变化；画布与视频预览复用同一 URL。独立测试页浏览器 error 日志为空。数量 1×→2×→1×回显正确，菜单与按钮实测均宽约 47.995 CSS px，向上间隔约 4px。证据与限制见根目录 design-qa.md 的 0.2.13 记录。

边界：缓存的 256MiB/96 项限制用于闲置条目，活动引用优先保留，不能当成整个页面的硬内存上限；首次远程媒体仍受大小和带宽影响。本轮没有进行千级节点或跨天长时间压力验证，也未调用真实收费模型。
