# 升级到单层收藏夹

供已有素材库的用户和接入素材工具的开发者，在安装 0.3.0-preview.26 前检查数据兼容性。

## 变更

库内 SQLite 由版本 4 升为版本 5，旧子文件夹提升为独立收藏夹。同名项保留各自 ID，并给重名项加编号；素材、归属、标签、备注与原文件均保留。父收藏夹不再隐式包含旧子文件夹的素材。版本 3 的旧收藏夹也可以直接升级。

素材工具 collections 只接受 create、rename、delete，移除 move 与 parent_id；collection 远程接口同步移除 parentId，分类结果不再包含 parentId。查询只匹配直接归属，不再使用 includeDescendants。更新依赖这些字段的调用者。

## 迁移

1. 停止使用素材库的宿主，备份完整库目录（含 library.json、library.sqlite、原件和预览）。
2. 安装新包并重新打开素材库，自动执行事务升级。检查收藏夹名称、素材数量和归属，重名项会显示编号。
3. 导入旧 ZIP 时同样平铺层级；新 ZIP 保持格式版本 2。旧插件不能打开版本 5 数据库。如需退回旧插件，恢复升级前完整备份，不修改数据库版本号。
