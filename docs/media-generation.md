# 图片与视频生成

## 目标与验收

图片、视频节点通过火山原生 API 或 Agent Plan 生成，文本继续复用 DSH。供应商配置放在 DSH 原生设置的「创作」中。文字状态显示在文字卡片；媒体卡片显示生成动效，发送按钮显示忙碌，错误和重试位于输入区；提示词始终可编辑。

- 保存 API 地址、密钥、模式与模型；密钥不返回客户端。
- 图片支持比例、清晰度、数量与参考图；视频支持比例、清晰度、时长、首帧与生成音频，参数由模型能力限制。
- 任务持久化，视频任务记录远程 ID 并恢复轮询；不自动重发结果不明的付费提交。
- 结果下载到项目媒体目录；失败可重试，取消本地等待并尽力取消远程视频任务。
- 生成卡片与预览展示供应商返回的用量；不要求手填价格，不把未知费用显示为零。历史估算保留原标记。

## 本次任务：火山模型发现（2026-10-27）

用户确定：首期只接火山；供应商填 Key 后进入模型选择，搜索、图片/视频筛选、批量添加；生成参数随模型能力显示，取消手选能力预设的主流程。

验收：新建原生/Agent Plan 连接 → 获取目录 → 勾选图片/视频模型 → 保存 → 节点选择后使用对应参数；刷新能发现官方新增 ID，不替换已添加模型与任务快照。重复添加应去重，切换模式不能带入另一模式的模型 ID。获取失败显示缓存来源、更新时间与重试；未知协议不能伪装已适配。

接口依据：[官方模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh)、[Agent Plan 视觉模型](https://docs.volcengine.com/docs/ark/agent-plan-personal-visual-models?lang=zh)、[图片 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)、[视频 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。火山管理面模型列表需要 Access Key；本次 Key-only 连接使用公开官方在线目录，明确标记“官方目录，调用权限未验证”，不声称账号模型发现或 Key 检验通过。目录请求不发送 API Key，不进行付费探测。

设计：Host 新增目录服务，限时、限体积读取官方 SSR 表格与参数说明；模型 ID 来自目录，参数支持范围来自对应官方参数说明。只有已实现的 Ark 图片/视频协议可以匹配，结构不明的条目保留为待适配。目录有本地缓存和随包基线，来源及更新时间可见；解析异常不覆盖有效缓存。shared 增加可校验的能力快照，已有 preset 配置仍可读取；新模型直接保存能力快照。Client 使用 DSH Modal/Input/Menu/Button 实现连接与模型选择，默认参数面板复用画布参数来源。

影响：media-contracts、media-settings（Host/Client）、新增 volc-catalog 服务与模型选择组件、contracts/index 端点、provider 参数构建、样式与双语文案。验证先覆盖真实官方响应的解析、在线更新/缓存降级、去重、旧配置兼容及按能力构建请求，再运行类型检查/构建、隔离 profile 的安装与界面主流程。真实收费调用未纳入本次自动验证。

当前状态：代码与本地测试已完成，已用真实只读请求验证官方刷新（原生 12 条、Plan 6 条）；本轮界面安装验证见末尾记录。公开文档格式不是稳定的模型元数据 API，解析严格校验并失败降级；兼容 SSR 表格与 router JSON 内的 Markdown 正文，全新协议仍需更新适配器。首期应用参考输入最多 12 项，当前仅接图片/文本，尚未开放视频/音频参考。

## 配置与实现

用户确定的结构为「供应商连接 → 多个图片/视频模型」。支持多个原生和 Plan 连接，各自保存 Base URL / API Key；每个模型有稳定内部 ID、显示名称、实际模型或接入点 ID、能力快照、启用开关和默认参数；旧估算单价字段兼容读取。公开设置只有 `hasKey`，保存空密钥保留旧值。设置使用 revision 防止覆盖另一处修改，同一连接禁止重复添加同一个模型 ID。

新添加模型从官方目录取得精确 ID 和能力快照，不从名称或 API Key 推断权限。原有 Seedream / Seedance preset 继续读取，不要求用户重新配置。公开目录在 `$DSH_HOME/creative-studio/catalog/volc-models.json` 原子保存，不含 Key；同一小时内复用，点击刷新立即重取，失败保留有效缓存；首启离线使用随包目录并标注来源和时间。新增模型不会自动启用，更新已有模型能力需显式点击「更新参数」并保存。尚未接入管理面账号发现或实时账单，不提供其他供应商的非兼容协议适配。

模型和任务存储在 `creative_media` v1。任务快照不含密钥；保存所用模型、参数、提示词、参考、计费方式和接口用量；历史预估费用兼容读取。一个数量对应一个独立请求，最多两个并发，最多二十个待处理。一次提交 requestId 幂等；批量持久化失败不开始付费请求。恢复已创建视频任务和已有下载链接；结果不明的同步请求保持待核对。已知失败后手动重新生成可能计费，继续获取已有结果不重新提交生成。

原始文件流式写入 `.part`，限制 256 MiB 并检查媒体签名，成功后原子改名和保存记录。参考图片从本地或素材库读入，单图上限 10 MiB、总计 40 MiB。首版视频参考支持图片、文本；视频/音频参考仍未接入。

新调用不再读取历史手填单价来估算费用。接口 `usage` 的生成数量、Token 和工具计数直接保存并展示；Plan 标记套餐用量，按量调用提示以供应商账单为准。当前生成 API 未声明逐请求实付金额字段，尚未接入账单查询。

## 接口依据
