# 模板库

## 目标与验收

模板库提供图片、视频和画布三个类型。图片模板来自 Image Prompt Registry，画布模板由用户从本地项目保存。视频模板仍待接入。

打开项目后，在顶栏「更多操作」中选择「保存为模板」。名称默认使用项目名，可在保存前修改。保存以当前已落盘的画布为准，包含节点、连线、布局、提示词、模型参数和素材引用。模板库的「画布」使用与「我的项目」一致的卡片，显示模板名称、节点数、保存日期和图片封面。模板与原项目分开保存，原项目后续编辑不影响模板。项目会话、生成任务及文本版本历史不随模板复制。

在管理页的「模板库 → 画布」可从模板创建独立项目。在画布的模板库打开「画布」可插入当前项目，插入是一次可撤销的编辑。每次复用生成新节点与连线 ID，并更新提示词引用与首尾帧引用。项目媒体复用原有本地文件，素材库引用仍指向原素材。引用资源不可用时，保存或使用会报告缺失素材。

在管理页打开画布模板卡片的「更多操作」，选择「删除模板」并确认。删除以选中的模板为准。同名模板、原项目、从模板创建的项目与引用的素材均保留。

图片模板支持搜索、用途分类、来源和原模型筛选、收藏、效果与提示词详情。全局页签下直接显示工具栏，不重复模板库标题；搜索和类型切换复用项目、素材页的共享组件，窄窗口下搜索换行。用途、来源和原模型集中在右侧筛选抽屉，重置与完成固定在底部，打开时不压缩结果网格。更新目录位于更多菜单。从项目列表使用时创建图片画布并选中新节点；在画布使用时新增图片生成节点，不改变缩放。模板提供的独立参考图默认选中；没有独立参考图时，默认选中效果图作为风格参考，可取消。所选图片保存到本地项目媒体，并以独立节点连入生成节点，填写 referenceIds。应用不会触发付费生成或切换模型。保持原有项目、素材与凭据。

## 接口与结构

基线为 DSH 0.2.1-rc.3，复用原生 Slots、Menu、Modal、Button、Input、语义主题与中英文 locale。Host 经现有 Typert 通道提供目录和收藏；Client 复用同一模板库组件展示页面与画布弹窗，不新增应用壳。

来源为 https://github.com/yukkcat/image-prompts 的 dist/manifest.json 与清单声明的 dist/sources/*.json。使用逐源 SHA-256，不将 registryHash 误作合并文件校验值。记录遵循其 schema version 1：保留标题、提示词、封面、标签、原模型、作者与来源。用途归并采用可审查的规则，并保留原始标签。未知模型与参考要求不推断为已支持。

Host 按 48 条分页查询，跨来源交错展示，避免单渠道占满首屏；单次同步限 45 秒、逐源 6 MiB、总计 20 MiB 和 10,000 条记录。目录有效期 24 小时；已有缓存立即展示，过期后后台更新，也可主动刷新。核验 manifest 声明的 SHA-256 后原子替换缓存；合并并发刷新，取消与卸载释放请求。失败保留上次有效目录并允许重试。收藏独立持久化，不随目录刷新清空。预览按需加载，不将外部提示词或 HTML 当代码执行。来源授权不因聚合改变，详情保留原作者和出处。

上游 referenceImageUrls 的语义并不完全一致：部分解析器把效果图也写入此字段，因此客户端先按 URL 与封面去重，将封面明确标为「效果图作参考」。独立附图依上游声明默认勾选；没有独立附图时，默认选中效果图，避免应用后只剩文字。用户可逐张取消或自行补图。不能仅凭「参考」字样猜测缺失的原图。依据为上游 [解析器](https://github.com/yukkcat/image-prompts/blob/main/prompt_registry/parsers.py) 与 [格式说明](https://github.com/yukkcat/image-prompts/blob/main/docs/prompt-format.md)。

templateMedia 接口只接受已缓存模板内声明的图片 URL。Host 校验 HTTPS、公开图片源域名与每一跳重定向，限制单图 12 MiB、总计 48 MiB、24 张和 60 秒，再复用项目媒体的格式校验与文件存储。jsDelivr 的 GitHub 文件地址失败时可回退到同一仓库、版本和路径的 raw 地址；不切换到任意镜像。下载失败不添加半套节点，详情保留以便取消问题图片后重试；新建画布失败时移除本次新建的空项目。下载完成后的媒体不再依赖外站 URL。详情弹窗沿用 DSH 原生 Modal，限制宿主可用高度，长正文内部滚动，底部操作保留可见。

## 验证路径

业务测试覆盖目录校验、缓存回退、收藏、分类、下载来源和格式限制、取消与卸载，以及本地参考节点和连线保存。运行类型检查、相关测试、构建、兼容和分发检查；在隔离 creative-test profile 检查真实图片、筛选、详情、收藏、模板应用、暗色/浅色及受限内容宽度。不调用付费生成。

## 当前状态

源码已实现：shared/template-contracts.ts 定义渠道与分类规则，host/template-library.ts 负责校验、缓存与收藏，host/template-media.ts 下载所选附图，client/template-library.tsx 复用页面和画布弹窗。template-application.ts 构造生成节点与所选图片参考，继承当前画布生成偏好，不复用上游模型。

目录和模板应用曾通过 87 项业务测试、类型检查、构建、安装包与 0.2.1-rc.3 真实兼容检查；真实同步核验获得 7 个来源、1,742 条记录。已在隔离 creative-test 安装，并实测组合筛选、详情、收藏、页面新建画布及画布内使用提示词；均未调用生成接口。966px 预览窗口内，侧栏展开与收起分别显示两列与三列卡片，浅色/深色可读。补充实测：800px 高窗口内，画布嵌套打开长 Bento 模板详情，上下均留 24px，关闭与使用按钮可见；苹果风格海报的真实参考图下载为本地 JPEG，在新画布和当前画布都带入节点、自动连线并显示输入参考缩略图，应用不改变 68% 缩放。另用「幼儿词汇拆解学习卡」回归验证只有效果图的记录：默认选中效果图，应用后得到本地参考图节点、连线及输入框参考缩略图。当前机器的预览进程显式沿用已开启的系统代理；插件需要宿主进程能够访问公开图片来源。外部聚合源仅包含图片；画布模板使用本地项目存储，视频目录仍待接入。来源效果图仍由原站提供，失效时保留占位与提示词。三类管理页面统一组件后的验收见 [界面验收](../design-qa.md#2026-11-14-集合页面与共享组件)。
