# 模板库

## 目标与验收

用户确定的层级：图片 / 视频 / 画布为模板类型，其下按用途分类；来源与模型作为筛选，收藏属于当前类型的浏览方式。第一阶段接入 Image Prompt Registry 的真实图片记录，视频和画布明确标为待接入，不制造示例数量或假模板。

图片模板支持搜索、用途分类、来源和原模型筛选、收藏、效果与提示词详情。页面直接显示类型、搜索与筛选，不重复标题说明、数量与更新时间；更新按钮放在搜索框右侧。用途分类单行显示，「全部」固定在左，其余支持触控板横滑、鼠标滚轮与键盘焦点滚动。从项目列表使用时创建图片画布并选中新节点；在画布使用时新增图片生成节点。只填入提示词，不触发付费生成、不自动切换到未配置的模型、不把效果图当成参考输入。用户自行选择必需参考图。保持原有项目、素材与凭据。

## 接口与结构

基线为 DSH 0.2.1-rc.3，复用原生 Slots、Menu、Modal、Button、Input、语义主题与中英文 locale。Host 经现有 Typert 通道提供目录和收藏；Client 复用同一模板库组件展示页面与画布弹窗，不新增应用壳。

来源为 https://github.com/yukkcat/image-prompts 的 dist/manifest.json 与清单声明的 dist/sources/*.json。使用逐源 SHA-256，不将 registryHash 误作合并文件校验值。记录遵循其 schema version 1：保留标题、提示词、封面、标签、原模型、作者与来源。用途归并采用可审查的规则，并保留原始标签。未知模型与参考要求不推断为已支持。

Host 按 48 条分页查询，跨来源交错展示，避免单渠道占满首屏；单次同步限 45 秒、逐源 6 MiB、总计 20 MiB 和 10,000 条记录。目录有效期 24 小时；已有缓存立即展示，过期后后台更新，也可主动刷新。核验 manifest 声明的 SHA-256 后原子替换缓存；合并并发刷新，取消与卸载释放请求。失败保留上次有效目录并允许重试。收藏独立持久化，不随目录刷新清空。预览按需加载，不将外部提示词或 HTML 当代码执行。来源授权不因聚合改变，详情保留原作者和出处。

## 验证路径

业务测试覆盖目录校验、缓存回退、收藏、分类及模板应用不生成或覆盖媒体。运行类型检查、相关测试、构建、兼容和分发检查；在隔离 creative-test profile 检查真实图片、筛选、详情、收藏、模板应用、暗色/浅色及受限内容宽度。不调用付费生成。

## 当前状态

源码已实现：shared/template-contracts.ts 定义渠道与分类规则，host/template-library.ts 负责校验、缓存与收藏，client/template-library.tsx 复用页面和画布弹窗。template-application.ts 只构造新的图片节点，继承当前画布生成偏好，不复用上游示例的媒体与模型。

已通过 81 项业务测试、类型检查和构建；真实同步核验获得 7 个来源、1,742 条记录。已在 DSH 0.2.1-rc.3 隔离 creative-test 安装，并实测组合筛选、详情、收藏、页面新建画布及画布内使用提示词；均未调用生成接口。966px 预览窗口内，侧栏展开与收起分别显示两列与三列卡片，浅色/深色可读。首批聚合源仅包含图片；视频与画布的接入协议留待有真实来源时扩展。来源效果图仍由原站提供，失效时保留占位与提示词。
