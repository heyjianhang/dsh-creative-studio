# 文本节点生成

## 目标与验收

文本节点正文与 AI 指令分开保存。选中节点出现悬浮生成面板，支持画布参考、结构化 @ 引用、DSH 已配置模型、1–4 个结果。正文可直接编辑。参考选择不改变目标节点，空节点、视频、自引用及循环引用不可选；已经附加、@ 或连线的来源也统一变暗模糊，禁止重复选择，但仍是有效的生成上下文。Esc 返回输入。未 @ 的参考仍发送，重复 @ 不重复上传。切换模型只修改节点配置。

面板从小尺寸参考缩略图开始，不显示标题及编辑/复制/删除工具栏。@ 候选和正文中的引用均带缩略图，名称超长省略，引用整体删除、复制及持久化仍使用节点 ID；预览地址只存在于渲染层。模型选择与图片/视频共用菜单：不显示搜索框，图标、名称和厂商同排，实际图片能力单独显示标签，选中项右侧勾选；支持方向键与回车。数量使用 4× 至 1× 的紧凑竖向菜单，发送为圆形向上箭头，生成中同一位置显示停止。验收覆盖长名称、重复引用、键盘选择、主题和窄屏布局，以及数量配置与实际队列一致。

面板最大宽度 660px，输入区最小高度 64px；正文 @ 芯片最大宽度 150px。芯片悬停时缩略图换为 ×，点击只移除当前这一次 @，不移除上方已附加的参考，并支持撤销。上方参考缩略图悬停时在其上方显示预览，底部叠加名称；正文 @ 悬停只在当前芯片上方显示预览图片，不重复名称，也不显示浏览器原生名称提示。

生成按独立任务排队，最多两个并发。每个任务可停止、失败后重试，流式文字和状态在画布卡片显示，停止/重试也可在卡片操作；输入面板保持可编辑。快照保存模型、指令、参考内容与原正文；关闭面板不停止后台任务，重启后中断任务标记失败，由用户决定重试，不自动重复计费。首个结果在原正文未变化时写回，其他结果或正文已编辑时新增节点。旧正文保留最近 20 个版本。任务写入与结果应用均可恢复，应用结果按任务 ID 去重。

模型指标只来自 DSH 0.2.1-rc.3 的精确路由元数据：context.contextWindow、defaultMaxTokens。分别标注上下文、默认输出，默认输出不是模型极限；按用户要求不展示推理档位。元数据最多四路并发，总等待上限 2.5 秒；缺失或查询失败时保留模型与已知输入能力，省略未知指标，不额外调用生成接口。

## 接口依据与实现

DSH 0.2.0-rc.2 的 llm.listProviders/listModels/resolveModelInfo/stream、agentDefaultModel.currentSelection、attachments.saveImages 为宿主入口；密钥不进入客户端。缺失 modalities 是未知，不能冒充支持图片；明确不支持图片时禁用相应参考并阻止提交。图片由宿主读取已保存节点的文件，通过附件服务校验和持久化，发送真实 image block，不能把本机 URL 交给模型。

Lexical 0.49 的公开编辑器、plain-text/history 和 token TextNode 实现输入与引用芯片，不依赖 DSH 私有输入框实现。用户参考是上下文数据，指令和系统提示词分离；系统提示词由本插件定义，并非竞品内部提示词。

修改 shared/contracts、host/index，新增 shared/text-generation（引用及应用规则）、host/text-generation（队列/快照/恢复）、host/text-runtime（DSH 适配）。新增 client/text-composer、prompt-editor；canvas 接入选择与正文编辑，样式沿用主题变量。独立 creative_text 域保存生成记录，不改变现有存储域版本。

## 验证与边界

已通过 Host/Client 类型检查、17 项测试和 npm pack 构建。测试覆盖引用去重/失效/循环、结果保护/重复应用、队列并发/取消/恢复/重试，以及 DSH 适配器向指定模型传递真实图片附件。隔离 creative-test 安装成功；4321 浏览器已显示悬浮面板、已配置模型、参考缩略图和 @ 芯片，未发现控制台错误。@ 支持紧接中文输入，无需先加空格。真实模型费用请求未执行，端到端生成质量仍待实际使用确认。

首版只接入文本与图片参考，视频理解和音频不在文本生成范围；图片/视频生成见[独立说明](media-generation.md)；每次最多 12 项参考，30,000 字符指令，120,000 字符文本参考总量，单图 16 MiB/合计 32 MiB 并受宿主更严格限制。
