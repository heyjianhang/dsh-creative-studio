# 创作 Agent 工作流

本文面向维护创作工作台与编写随包专家的研发人员，说明关联对话如何完成素材检索、项目创建、画布编辑、生成与结果交付，以及如何验证这条流程。

## 能力入口

从管理页右下角打开 AI，进入实例级对话，可以列出、创建和管理项目。从项目画布打开 AI，进入固定项目对话，只操作绑定项目；查看其他项目不改绑对话。普通新对话不加载创作工具与专家。随包 [创作助手 Skill](../skills/creative-studio-assistant/SKILL.md) 提供完整操作顺序，素材导入、检查与文件夹操作沿用素材助手。

| 工具 | 职责 |
| --- | --- |
| asset_library_list / search / inspect | 获取真实库与文件夹，按名称或已有索引找素材，检查图片或视频抽帧 |
| creative_projects | 列出摘要或读取项目、节点、连线与最新 revision |
| creative_project_create | 用请求 UUID 创建持久项目，重复提交不重复创建 |
| creative_canvas_edit | 原子增改删除节点、排版、编辑提示词及模型参数、建立或断开参考 |
| creative_project_open | 通过原生展示通道打开指定项目，保持调用对话关联 |
| creative_models | 查询启用的文字、图片与视频模型及能力，不返回密钥 |
| creative_generate | 使用已保存节点配置提交任务，以请求 UUID 恢复同一次提交 |
| creative_generation_jobs | 查询、取消或重试任务；重新应用已完成但未写入画布的结果 |

creative_add_text 与 creative_assets_search 保留为兼容入口。新流程优先使用批量画布编辑及素材库工具。

## 数据与执行

画布编辑复用 Projects 比较版本与写入队列，素材元数据由素材服务解析。模型只能提交素材 ID，不能指定媒体内部路径。整个编辑批次通过图校验后才保存；无效引用、循环、节点类型变化、旧版本或磁盘失败均不会提交部分画布。局部生成参数只替换明确提供的字段。

文字复用 DSH 模型服务，图片视频复用创作现有供应商连接、参数校验与任务队列。上传和素材库原件保留，生成使用独立目标节点；已生成节点可继续生成。请求返回任务不表示结果完成，状态区分排队、运行、下载、完成、失败、取消和不确定提交。供应商结果不确定时不自动重新计费提交。

Host 将完成结果合并到最新项目，原画布未打开也能保存。纯结果应用函数携带已应用任务 ID，确认记录写入失败或宿主重启后不会重复增加节点。完成但 applied=false 时查询会重试落盘，不重新调用供应商；存储问题同时写入任务错误并显示在界面。用户编辑与生成结果写入不同节点或同一节点的不同字段时，画布会自动合并并保存。两边改动同一字段或合并后连线无效时，画布保留草稿，可用「下载草稿并重载」打开已保存版本。

打开项目要求 ACTVERO 扩展 API 1.7。原生展示返回 confirmed 只确认宿主界面挂载，业务内容读取由工作台处理；没有客户端、多个客户端、对象不存在、取消及展示超时按真实状态返回。

## 验证与限制

npm run typecheck、npm test 与 npm run build 检查类型、业务回归及发布入口。assistant-workflow.test.ts 使用真实工具定义验证创建、素材解析、编辑、生成和重读；native-workbench.test.ts 验证原生激活和固定项目；media-generation.test.ts 覆盖模拟图片视频供应商、取消、未知提交、重启和结果恢复；unified-folders.test.ts 使用真实 SQLite 检查元数据与目录兼容。

安装前运行 npm run check:package 与 npm run check:compatibility，并由目标宿主执行工作台包检查。隔离 DSH_HOME 中验证原生入口、Skill、工具、关联对话及页面重读；不替换个人配置。真实账户的模型自主调用、付费生成、付费向量索引和 S3 联网属于独立验收，模拟供应商测试不代替这些结果。生成结果自动归档到共享素材库仍未提供。
